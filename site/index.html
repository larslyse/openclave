Your own team of AI agents.

Each agent has one area of your life: training, the house, the car, money, writing. You talk to them from a browser or your phone. They run on your own computer and keep their notes, plans and chats as plain Markdown files, so they remember what you told them last month and you can read everything they know.

What people use it for

Start from ready-made agents, or describe your own. Each one interviews you for a few minutes to fit itself to you.

Training and rehab

"Knee ached on the last 3 km of Sunday's run."

Asks where it hurts, cuts next week's runs, adds exercises with a stop rule, and moves the long run in your plan.

Home Assistant

"Warn me if the garage door is open after 22:00."

Writes the automation in your Home Assistant, tests it, and tells you which sensor batteries are running low. Asks before anything risky.

Fixing an old house

"Floor feels soft by the shower."

Tells you what to check first, reads your photos, and walks you through the repair step by step.

Money

"Quote for 8 kW solar: is it worth it?"

Builds a model with every assumption written out and saves it to its files, so you can change a number and ask again.

Writing and notes

"Turn my notes into a short post. Keep my words."

Orders and joins your notes without rewriting them, and marks where they contradict each other. Can write into your Obsidian vault.

A manager for the rest

Once a week, on its own.

Archives old chats, spots agents that overlap, and collects bugs and ideas. You give it its name.

On your phone too

Same agents, same chats. Reach it from anywhere with Tailscale (free), and use voice if you like.

How it works

Runs at home

On your laptop, an old PC or a small home server. No account with us, no cloud of ours. Your data stays on your disk.

Plain files

Every agent is a folder: mission, plan, backlog, files and chats as Markdown. Open them in any editor or Obsidian, back them up like anything else.

Your choice of model

An Anthropic or xAI API key (pay per use, a few dollars a month for light use), or the Claude or ChatGPT subscription you already pay for.

Agents that work together

Agents can message each other, share a group chat, run scheduled tasks and remind you. Group them into claves: home, work, hobbies.

Install

Open a terminal and paste:

curl -fsSL https://getopenclave.com/install.sh | bash

Or the same thing with git:

git clone https://github.com/larslyse/openclave.git && cd openclave && ./install.sh

The installer asks a few questions (what to call you, your timezone, which model), then opens http://localhost:8777. Run it again any time; it keeps your settings and agents.

  • You need: Ubuntu or Debian, or Windows with WSL.
  • And one of: an Anthropic API key, an xAI key, Claude Pro/Max, or ChatGPT Plus/Pro.
  • Early software: it runs every day for its author, but you are among the first to install it. If something fails or confuses you, please report it.

What the installer runs

Piping a script into bash means trusting it, so here is what install.sh does, in order. It runs as your normal user and only uses sudo for the steps marked (sudo).

  1. Checks that you're on Ubuntu or Debian (or WSL), not root, with Python 3.12 or newer.
  2. Installs missing basics with apt: git, curl, python3, python3-venv (sudo).
  3. Downloads OpenClave with git clone to ~/openclave, or updates it there if it's already present.
  4. Installs its Python packages into ~/openclave/.venv. Nothing system-wide.
  5. Asks about you: your name and timezone, saved to ~/.openclave/openclave.toml.
  6. Asks about your manager agent: its name, personality, and any changes to its job.
  7. Sets up a model, the one you pick:
    • API key (Anthropic or xAI): checked against the provider, saved to ~/.openclave/.env (only you can read it).
    • Claude Pro/Max: installs Claude Code from claude.ai and lets you sign in.
    • ChatGPT Plus/Pro: installs Node.js 22 (NodeSource), bubblewrap and the Codex CLI, plus an AppArmor rule on Ubuntu 24.04+ so Codex's sandbox works, then lets you sign in (sudo).
  8. Optional, asks first: note search (qmd, through npm) (sudo), and a systemd service so OpenClave starts with the computer (sudo).
  9. Starts OpenClave on http://localhost:8777 and opens your browser.

Its only network use is downloading those packages and checking your API key with its provider. Want to read it first?

curl -fsSL https://getopenclave.com/install.sh -o install.sh && less install.sh && bash install.sh
