AI chats get messy fast.
OpenClave keeps them in order.

A private workspace for doing many things with AI at once. Your work is sorted into agents, each with one area of your life, and each agent's chats are sorted into topics. A manager agent tidies up every week. It runs on your own computer, and everything is a Markdown file you can read.

curl -fsSL https://getopenclave.com/install.sh | bash

Ubuntu, Debian or Windows with WSL. Free and open source (AGPL-3.0). What you need · What the installer runs

Why use it

A chat app gives you one long list of conversations. After a few months you can't find the answer you got in March unless you remember the words to search for. People keep things in buckets, so OpenClave gives you two layers of them, and someone to keep them tidy.

1. Agents are the first bucket

One agent per area: training, the house, money, writing. Each has a name, a job and its own memory, plan and backlog. You know whom to ask, the same way you know which colleague to ask.

2. Topics are the second

Inside an agent, chats sit in topics you name. Drag a chat into one. A new question goes in a new chat, so each chat stays about one thing.

3. A manager keeps it that way

One agent has the job of looking after the others. Once a week it archives what's finished, writes a recap of each chat, and brings you a short list of yes/no proposals.

What it looks like

The dashboard: everything at once

Every agent in its own box with its latest chat and a message box. Ask the house agent something, then the money agent, and read the answers as they come in. Nothing is hidden in a tab. This is the screenshot at the top of the page.

The agent page: chats, plan and backlog side by side

Topics and chats on the left, the chat in the middle, the agent's plan and backlog on the right, and a small kanban board below. The agent updates the plan and ticks off the backlog as you talk. Tabs at the top switch agent.

Claves: teams, when one group isn't enough

Group agents into teams (claves) such as Home, Health and Work. Each has a lead, a group chat and a shared backlog. Pick a clave and the dashboard shows only that team.

Your data, on your disk

Every agent is a folder of plain Markdown: mission, plan, backlog, notes, chats. Open it in any editor or Obsidian. No account with us; only what you send to the model leaves your computer.

Agents that follow up

They remember what you said last month, message each other, run scheduled tasks and send reminders to your phone.

Asks before anything risky

Home Assistant changes wait for your OK. Agents only write to the notes you allow.

Plain Python, yours to change

Your agents and settings live outside the code, so you can change anything and still update with git pull.

What people use it for

Start from ready-made agents, or describe your own. Each one interviews you for a few minutes to fit itself to you.

Training and rehab

"Knee ached on the last 3 km of Sunday's run."

Asks where it hurts, cuts next week's runs, adds exercises with a stop rule, and moves the long run in your plan.

Home Assistant

"Warn me if the garage door is open after 22:00."

Writes the automation in your Home Assistant, tests it, and tells you which sensor batteries are running low.

Fixing an old house

"Floor feels soft by the shower."

Tells you what to check first, reads your photos, and walks you through the repair step by step.

Money

"Quote for 8 kW solar: is it worth it?"

Builds a model with every assumption written out and saves it to its files, so you can change a number and ask again.

Writing and notes

"Turn my notes into a short post. Keep my words."

Orders and joins your notes without rewriting them, and marks where they contradict each other. Can write into your Obsidian vault.

The manager

Once a week, on its own.

Archives old chats, spots agents that overlap, and collects bugs and ideas. You give it its name and personality.

Install

Open a terminal and paste:

curl -fsSL https://getopenclave.com/install.sh | bash

Or the same thing with git:

git clone https://github.com/larslyse/openclave.git && cd openclave && python3 updater.py first-checkout && ./install.sh

The installer asks a few questions (what to call you, your timezone, which model), then opens http://localhost:8777. Run it again any time; it keeps your settings and agents.

What the installer runs

Piping a script into bash means trusting it, so here is what install.sh does, in order. It runs as your normal user and only uses sudo for the steps marked (sudo).

  1. Checks that you're on Ubuntu or Debian (or WSL), not root, with Python 3.12 or newer.
  2. Installs missing basics with apt: git, curl, python3, python3-venv (sudo).
  3. Downloads OpenClave with git clone to ~/openclave and picks the newest release, or updates it there if it's already present. Then it carries on with the install.sh of that version.
  4. Installs its Python packages into ~/openclave/.venv. Nothing system-wide. Links the openclave command into ~/.local/bin.
  5. Asks about you: your name and timezone, saved to ~/.openclave/openclave.toml.
  6. Sets up a model, the one you pick:
    • API key (Anthropic or xAI): checked against the provider, saved to ~/.openclave/.env (only you can read it).
    • Claude Pro/Max: installs Claude Code from claude.ai and lets you sign in.
    • ChatGPT Plus/Pro: installs Node.js 22 (NodeSource), bubblewrap and the Codex CLI, plus an AppArmor rule on Ubuntu 24.04+ so Codex's sandbox works, then lets you sign in (sudo).
  7. Optional, asks first: note search (qmd, through npm) (sudo), and a systemd service so OpenClave starts with the computer (sudo).
  8. Picks the port: the one in openclave.toml (8777 unless you set another). If another program uses it, it takes the next free one and saves it there (asks first if you already had settings).
  9. On a computer without a screen, asks first: if Tailscale is signed in, runs tailscale serve --bg <port> for a private HTTPS address and saves it as public_url in openclave.toml (sudo) if Tailscale needs it. On WSL it explains how to keep OpenClave running.
  10. Starts OpenClave on http://localhost:8777 and opens your browser.

Your manager agent and your first agents you set up on the welcome card in the browser. With --ask-all (curl -fsSL https://getopenclave.com/install.sh | bash -s -- --ask-all) the installer asks about them too: before the model step your manager's name, personality, extra jobs and changes to its job, and after it which ready-made agents to start with.

Its only network use is downloading those packages and checking your API key with its provider. Want to read it first?

curl -fsSL https://getopenclave.com/install.sh -o install.sh && less install.sh && bash install.sh
