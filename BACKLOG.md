# OpenClave backlog

The working backlog is the Markdown note configured as `[paths].project_backlog`
in `$OPENCLAVE_HOME/openclave.toml`, a path relative to `vault_root`.

The maintainer's Backlog pane and `update_backlog` tool read and write that
note. Other agents keep their own backlogs. The original release plan remains
available in this file's Git history.
