Needs attention

Checked from each agent's own files, no AI involved. Bold needs you and puts the amber dot on the agent: a measurement log with no entry for 7 days, open items in the maintainer inbox, an agent on a model that can't reach its connection. Grey is upkeep for the agent (a plan or backlog untouched for 14 days while you're using it): the agent is asked to bring it up to date itself. The digest push (Settings) sends only what needs you.

Model updates

Once a day OpenClave checks the providers. A model newer than everything it has from that provider gets a test reply; if it answers, the weekly review suggests adding it (Suggest adding new models above). Old models, and ones the provider dropped, are suggested for removal (Suggest removing old models). Nothing is added or hidden until you say yes, and models an agent uses are never suggested. Nothing is deleted: Restore brings a model back, Remove hides one for good.

Reminders

Agents with the schedule_reminder tool can send you a message later. It arrives as a push notification and in that agent's Reminders conversation. Usually the text is fixed when it's scheduled. A reminder marked 'written when due' runs the agent once at send time to look something up first (e.g. the weather); it can only look things up then, and Home Assistant is read-only.
